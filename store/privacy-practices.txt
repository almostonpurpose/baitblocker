1. SINGLE PURPOSE DESCRIPTION
=============================================================================
BaitBlocker annotates the page you are reading to show where its wording uses a
known persuasion pattern, and explains each one in place.

=============================================================================
2. HOST PERMISSION JUSTIFICATION   (the one reviewers push back on)
=============================================================================
The extension's only function is annotating the page the user is reading.
Persuasion patterns appear on any site - retail, news, social, booking - so the
user cannot be asked to predeclare where to look. The content script reads
visible text in the page and marks it there. It runs in all frames because
booking timers and engagement bait are routinely rendered inside iframes. No
page content is stored, transmitted, or sent off the device, and the extension
makes no network requests.

=============================================================================
3. activeTab JUSTIFICATION
=============================================================================
Lets the toolbar popup message the page the user is currently looking at, so
clicking an entry in the popup's list scrolls to that mark on the page. Used
only while the popup is open.

=============================================================================
4. storage JUSTIFICATION
=============================================================================
Saves the user's own settings (which categories are on, sensitivity, and the
list of sites they have paused) and a local count of pages scanned and patterns
found. No page content and no URLs beyond the user's own pause list. All of it
stays in the browser.

=============================================================================
5. webNavigation JUSTIFICATION
=============================================================================
Detects top-level and subframe navigation so the toolbar count resets on a new
page, and so findings belonging to frames that no longer exist are retired
instead of being reported as still present.

=============================================================================
